# A01.1 — Bootstrap Expo, struktura i Hello World Liquid Glass

**Milestone:** A — Fundament  
**Epic:** A01 — Konfiguracja aplikacji  
**Story / rezultat:** Uruchamialny szkielet React Native + Expo + TypeScript z **jednym ekranem Hello World w pojedynczej karcie Liquid Glass**.  
**Status:** Backlog  
**Zależności:** brak  
**Interactive Planning Gate:** required  
**Powiązane dokumenty:** `AGENTS.md`, `PROGRESS.md`, `docs/04-design-system.md`, `docs/06-architecture.md`, `docs/10-agent-workflow.md`, `docs/12-implementation-decisions.md`, `skills/interactive-planning/SKILL.md`, `reference/stitch-original.txt`

## Przed implementacją — wymagana interaktywna ankieta
- Zbadaj repo i wersje bibliotek. Zapytaj o nieustalone wybory: Expo SDK i workflow, npm/pnpm/yarn, NativeWind i zgodną wersję Tailwind versus StyleSheet, struktura folderów, wariant Glass (prawdziwy blur czy bezpieczny fallback), routing jednego ekranu, dark/light i preferowany sposób lokalnej weryfikacji iOS.
- Nie zakładaj odpowiedzi i nie powtarzaj decyzji już zapisanych w dokumentacji.
- Pytaj w krótkich rundach, proponuj rekomendację wraz z kompromisem. Pokaż spójny plan i poczekaj na wyraźną zgodę.
- Zatwierdzone wybory zaproponuj do `docs/12-implementation-decisions.md`; sam zapis wymaga zgody zgodnie z workflow.

## Scope
- Bootstrap projektu Expo/React Native/TypeScript, spójna struktura katalogów, skrypty start/typecheck/lint, instalacja wyłącznie niezbędnych zależności w wersjach kompatybilnych z wybranym Expo SDK.
- Przenieś paletę i podstawowe tokeny Stitch do **jednego źródła tokenów**; jeśli wybrano NativeWind, skonfiguruj odpowiadający mu Tailwind i mapowanie tokenów, bez mechanicznego kopiowania CSS webowego.
- Utwórz jeden ekran wyświetlający dosłownie `Hello World` w pojedynczej karcie w estetyce Liquid Glass; bez danych finansowych. Zapewnij czytelny tekst i sensowny fallback dla blur.
- Konfiguracja uruchamiania na iOS/Expo i krótkie komendy w README lub dokumencie setupu, tylko gdy potrzebne.

## Out of scope
- Pięć zakładek, nawigacja po funkcjach, dashboard, rzeczywiste modele finansowe, dane przykładowe, rozbudowany katalog komponentów.
- Framework testowy i testy komponentowe/E2E (A01.2), SQLite, backend, bank API, logowanie, pełne wdrożenie Light Mode.

## Acceptance criteria
- [ ] Ustalono w ankiecie wybory techniczne i użytkownik zaakceptował plan przed instalowaniem bibliotek lub edycją kodu.
- [ ] Projekt uruchamia się z jednym ekranem `Hello World` w karcie Liquid Glass bez wymaganego backendu.
- [ ] Jest jeden zestaw tokenów wizualnych, powiązany ze specyfikacją Stitch i zgodny z natywnym RN.
- [ ] Skrypty typecheck/lint działają albo konkretne ograniczenia są jawnie opisane.
- [ ] Nie powstały dodatkowe ekrany, funkcje finansowe ani przypadkowe zależności.
- [ ] Weryfikacja uruchomienia na iOS jest udokumentowana (wykonana lub wyraźnie oznaczona jako niewykonana).
